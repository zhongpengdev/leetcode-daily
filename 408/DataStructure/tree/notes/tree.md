# 二叉树的线索化

+ 普通二叉树中很多 left/right 是空指针，浪费了。线索化就是把空指针**改成指向前驱/后继的线索**。

+ **前驱/后继：** 中序遍历得到有序序列，序列中某个节点前面的是前驱，后面的是后继。

    ```
    中序遍历：1 → 3 → 4 → 5 → 6 → 7 → 8

    4 的前驱是 3，4 的后继是 5
    1 没有前驱，8 没有后继
    ```

+ **节点结构：** 需要标记位区分指针是"子节点"还是"线索"

    ```cpp
    struct ThreadNode {
        int value;
        ThreadNode *left, *right;
        int ltag, rtag;  // 0=子节点, 1=线索
        ThreadNode(int v) : value(v), left(nullptr), right(nullptr), ltag(0), rtag(0) {}
    };
    ```

+ **线索化过程：** 用 pre 指针记录"上一个被访问的节点"，中序遍历时：

    1. 当前节点没有左子节点 → left 指向 pre（前驱线索），ltag=1
    2. pre 没有右子节点 → pre 的 right 指向当前节点（后继线索），rtag=1
    3. 更新 pre = 当前节点

    遍历到 4 时，pre=3：
    - 4 没有左孩子 → 4.left = 3（前驱线索）
    - 3 没有右孩子 → 3.right = 4（后继线索）

+ **好处：** 中序遍历不需要递归也不需要栈，直接沿线索走，空间 O(1)
