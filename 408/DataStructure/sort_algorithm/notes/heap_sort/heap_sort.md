# 堆排序 (Heap Sort)

## 前置知识：什么是堆？

堆是一棵**完全二叉树**，用数组存。

只要是完全二叉树就行，且满足大顶堆和小顶堆就行，具体数值形状不唯一

```
数组：[9, 3, 7, 1, 8, 2, 5]

对应的完全二叉树：
          9              ← a[0]，根
        /   \
       3     7           ← a[1], a[2]
      / \   / \
     1   8 2   5         ← a[3], a[4], a[5], a[6]

父节点和孩子的关系（下标从0开始）：
  左孩子：2*i + 1
  右孩子：2*i + 2
  父节点：(i-1) / 2
```

**大顶堆**：每个节点 >= 它的孩子。堆顶是最大值。
**小顶堆**：每个节点 <= 它的孩子。堆顶是最小值。

堆排序用**大顶堆**。

## 核心操作：heapify（向下调整）

```
作用：以节点 i 为根，把大的往上提，维护大顶堆性质。

步骤：
1. 找 i、左孩子、右孩子中最大的
2. 如果最大的不是 i，交换，然后对被交换下去的那个位置继续递归调整
```

举例：对下面的堆，调整根节点0

```
调整前：        3（根比孩子小）
             /   \
            8     7
           / \
          1   5

第1步：3 < 8，交换0和1 →   8
                        /   \
                       3     7
                      / \
                     1   5

第2步：3 < 5，交换1和3 →   8
                        /   \
                       5     7
                      / \
                     1   3

调整完成，大顶堆恢复。
```

## 排序过程

```
原始：[4, 6, 8, 5, 2]

第一步：建大顶堆
  从最后一个非叶子节点 (n/2-1=1) 开始往上调
  节点1（值6）：左右孩子5和2，6最大，不用调
  节点0（值4）：左右孩子6和8，8最大，交换 → [8, 6, 4, 5, 2]
  继续调：节点2没孩子，结束

  大顶堆：[8, 6, 4, 5, 2]
           ↑ 最大值在堆顶

第二步：排序，重复 n-1 轮

  第1轮：堆顶8和末尾2交换 → [2, 6, 4, 5, |8]
          堆大小减1（不看8了），调整堆顶 → [6, 2, 4, 5, |8]
          再调：2 < 5 → [6, 5, 4, 2, |8]

  第2轮：堆顶6和末尾2交换 → [2, 5, 4, |6, 8]
          调整 → [5, 2, 4, |6, 8]

  第3轮：堆顶5和末尾4交换 → [4, 2, |5, 6, 8]
          调整 → [4, 2, |5, 6, 8]

  第4轮：堆顶4和末尾2交换 → [2, |4, 5, 6, 8]

  结果：[2, 4, 5, 6, 8]
```

## 代码逻辑

```cpp
heapSort(a, n):
    // 建堆：从最后的非叶子节点往上逐个heapify
    for i = n/2-1 到 0:
        heapify(a, n, i)

    // 排序：堆顶换末尾，缩小堆，继续heapify
    for i = n-1 到 1:
        swap(a[0], a[i])    // 最大值放到末尾
        heapify(a, i, 0)    // 对剩余部分调整

heapify(a, n, i):  // 向下调整
    largest = i
    if 左孩子 > a[largest]: largest = 左孩子
    if 右孩子 > a[largest]: largest = 右孩子
    if largest != i:
        swap(a[i], a[largest])
        heapify(a, n, largest)  // 递归往下调
```

## 复杂度

| | 时间 | 空间 |
|---|---|---|
| 建堆 | O(n) | — |
| 排序 | n 次 × heapify O(log n) = O(n log n) | — |
| **总计** | **O(n log n)**，最好最坏平均都是 | **O(1)**（就地） |
| 递归heapify栈 | — | O(log n) |

## 和快排、归并排序的对比

| | 快速排序 | 归并排序 | 堆排序 |
|---|---|---|---|
| 平均 | O(n log n)，常数最小 | O(n log n) | O(n log n)，常数较大 |
| 最坏 | O(n²) | O(n log n) | O(n log n) |
| 空间 | O(log n) | O(n) | O(1) |
| 稳定性 | 不稳定 | 稳定 | 不稳定 |

堆排序的优势：**最坏也是 O(n log n) 且只用 O(1) 空间**。
堆排序的劣势：缓存不友好（数组跳着访问），实际跑起来比快排慢。

## 稳定性

**不稳定。**

反例：`[4, 4, 1]`，两个4相等，但建堆和交换会打乱它们的相对顺序。
