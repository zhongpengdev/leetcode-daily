**逻辑地址**：32位系统逻辑地址范围是：$2^{32}-1$ 
+ 逻辑地址存在寄存器里面，而32位的计算机的寄存器是32位的。

**地址重定位**：逻辑地址转换成物理地址

**源程序到进程**：编译 -> 链接 -> 装入
+ 链接
  + 静态链接
  + 装入时动态链接
  + 运行时动态链接
+ 装入:
  + 静态装入：编译时转换好，不能移动
  + 可重定位装入：装入程序在程序装入时转换，装入后地址无法移动。
  + 动态运行时装入：程序在内存中可以移动，地址转换延迟到指令执行时做
    - 编译后指令里保留逻辑地址（100），装入时不改写
    - 运行时 CPU 有一个重定位寄存器（也叫基址寄存器）
  ，存着当前程序在内存的起始地址
    - 每次访问内存时，CPU 硬件自动算：逻辑地址 + 
  重定位寄存器的值 = 物理地址
    - 如果程序被换出再换入到不同位置，只需要更新重定位
  寄存器的值，指令本身不用改
