# 进程间消息传递

## 消息通信方式

1. 直接通信
2. 间接通信

## 间接通信的过程

1. 构建消息实体

2. 调用发送原语，执行`send()`

3. 内核缓冲区操作

   - 内核在mailbox中申请一个空闲的消息缓冲区
   - **第一次拷贝**：从用户进程拷贝到内核缓冲区

4. 挂载队列：将该缓冲区挂载到目标信箱的消息链表末尾。

5. 唤醒接收者：若接收者处于阻塞态(等待该信箱)使用`Wakeup()`原语唤醒接收者

6. 接受进程执行`Receive()`原语

7. **第二次拷贝**：从内核态拷贝到接收者用户空间，释放内存

```c
typedef struct {
    unit32_t sender_id;
    unit32_t msg_type;
    size_t payload_len;
    char payload[MAX_PAYLOAD_SIZE];
} Message;

// 原语封装
Status sys_send_to_mailbox(MailBoxID mbx_id, const Message *user_msg) {
    // 地址合法性检查
    if(!is_vaild_address(user_msg)) return ERR_INVAILD_MEM;

    // 关中断
    disable_interrupts();

    // 申请内核缓冲区
    KernelBuffer *kbuf = alloc_kernel_msg_buffer();

    // 拷贝到内核态
    copy_from_user(kbuf->data, user_msg, sizeof(Message));

    // mailbox队列
    enqueue_mailbox(mbox_id, kbuf);
    
    wakeup_blocked_receiver(mbox_id);

    enable_interrupts();

    return SUCCESS;
    }
```
