题目示例：

给定两个序列 $X = \{A, B, C, B, D, A, B\}$ 和 $Y = \{B, D, C, A, B, A\}$。写出求解最长公共子序列长度的递归方程。

计算它们的最长公共子序列长度（通常需要画表）。

备考要点（必背公式）：

如果 $X[i] == Y[j]$：$dp[i][j] = dp[i-1][j-1] + 1$ （这就是你说的拿左上角的值加1）

如果 $X[i] != Y[j]$：$dp[i][j] = \max(dp[i-1][j], dp[i][j-1])$ （拿上面和左边的最大值）

---

### 1. 递归方程 (状态转移方程)

设 $dp[i][j]$ 表示序列 $X$ 的前 $i$ 个字符和序列 $Y$ 的前 $j$ 个字符的最长公共子序列（LCS）的长度。
其中 $X$ 的长度为 $m$，$Y$ 的长度为 $n$。

**状态转移方程如下：**

$$
dp[i][j] = \begin{cases} 
0 & \text{若 } i=0 \text{ 或 } j=0 \\
dp[i-1][j-1] + 1 & \text{若 } i,j > 0 \text{ 且 } X[i] == Y[j] \\
\max(dp[i-1][j], dp[i][j-1]) & \text{若 } i,j > 0 \text{ 且 } X[i] \neq Y[j]
\end{cases}
$$

> **💡 考试小贴士：** > 只要写出这三行公式，这道题 30%~40% 的分数就到手了。记得要写清楚边界条件 ($i=0$ 或 $j=0$ 时为 0)。

---

### 2. 计算过程 (画表法)

**序列信息：**
* **X (行):** $\{A, B, C, B, D, A, B\}$ (长度 $m=7$)
* **Y (列):** $\{B, D, C, A, B, A\}$ (长度 $n=6$)

**填表规则（口诀）：**
1.  **相等时：** 看**左上角**，数值加 1。
2.  **不相等时：** 看**左边**和**上面**，谁大取谁。

**DP 表格如下：**

| $X \setminus Y$ | $\emptyset$ (0) | **B** (1) | **D** (2) | **C** (3) | **A** (4) | **B** (5) | **A** (6) |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **$\emptyset$ (0)** | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| **A (1)** | 0 | 0 | 0 | 0 | **1** | 1 | 1 |
| **B (2)** | 0 | **1** | 1 | 1 | 1 | **2** | 2 |
| **C (3)** | 0 | 1 | 1 | **2** | 2 | 2 | 2 |
| **B (4)** | 0 | **1** | 1 | 2 | 2 | **3** | 3 |
| **D (5)** | 0 | 1 | **2** | 2 | 2 | 3 | 3 |
| **A (6)** | 0 | 1 | 2 | 2 | **3** | 3 | **4** |
| **B (7)** | 0 | 1 | 2 | 2 | 3 | **4** | 4 |

---

### 3. 详细步骤解析 (举几个关键点)

为了让你看懂表是怎么填的，我们挑几个格子分析：

* **填 $dp[1][4]$ (X: A, Y: A)：**
    * 字符 $X[1] = 'A'$，$Y[4] = 'A'$。**相等！**
    * 操作：找左上角 $dp[0][3] = 0$。
    * 结果：$0 + 1 = \mathbf{1}$。

* **填 $dp[2][5]$ (X: B, Y: B)：**
    * 字符 $X[2] = 'B'$，$Y[5] = 'B'$。**相等！**
    * 操作：找左上角 $dp[1][4]$。我们刚才算过 $dp[1][4]=1$。
    * 结果：$1 + 1 = \mathbf{2}$。

* **填 $dp[2][2]$ (X: B, Y: D)：**
    * 字符 'B' 不等于 'D'。**不相等！**
    * 操作：看上面 $dp[1][2]=0$，看左边 $dp[2][1]=1$。取最大值。
    * 结果：$\max(0, 1) = \mathbf{1}$。

* **填 $dp[7][6]$ (最后一个格子)：**
    * 此时 X 走到最后一个 'B'，Y 走到最后一个 'A'。如果不相等，取 $\max(\text{左}, \text{上})$，即 $\max(4, 3) = 4$。
    * (注：表中 $dp[6][6]=4$，所以最后一个格子也是 4)。

---
### 4. 最终答案

**最长公共子序列的长度为：4**

> **附加分项 (如果老师让你写出具体的子序列)：**
> 通过从右下角的 4 开始**回溯**（即：如果是从左上角加过来的，就选中该字符；如果是继承左边或上面的，就往数值大的方向走），可以找到具体的序列。
>
> 常见的一个结果是：**B, D, A, B** (或者 B, C, A, B 等，LCS 可能不唯一，但长度一定是 4)。
>
> **路径参考：**
> 1. X(B) != Y(A) -> 往上走 (找 Y 的 B)
> 2. X(A) == Y(A) -> 选中 **A**，往左上走
> 3. X(D) != Y(B) -> 往上走 (找 Y 的 B)
> 4. X(B) == Y(B) -> 选中 **B**，往左上走 (注意这里可能有分歧，我们看前面的 C 和 D)
> ...以此类推。简单看 $Y=\{B, D, C, A, B, A\}$ 和 $X=\{A, B, C, B, D, A, B\}$，一眼能看出的最长重合确实是 **BCBA** 或 **BDAB**。
