### 📝 考试模拟题：0-1 背包问题算法设计

**题目描述：**
有一个背包，最大容量为 $C = 5$。现在有 4 件物品，它们的重量 $w$ 和价值 $v$ 如下表所示。
请设计一个动态规划算法，计算背包能装入物品的**最大总价值**，并给出具体的装入方案。

| 物品编号 ($i$) | 重量 ($w_i$) | 价值 ($v_i$) |
| :---: | :---: | :---: |
| 1 | 2 | 3 |
| 2 | 3 | 4 |
| 3 | 4 | 5 |
| 4 | 1 | 2 |

-----

### ✅ 满分标准答案

#### 1\. 算法设计思想（核心方程）

设 $dp[i][j]$ 表示前 $i$ 件物品装入容量为 $j$ 的背包中所能获得的最大价值。

**状态转移方程（必背！）：**

$$
dp[i][j] = 
\begin{cases} 
dp[i-1][j] & j < w_i \quad (\text{装不下，只能沿用上面的值}) \\
\max(dp[i-1][j], \ dp[i-1][j-w_i] + v_i) & j \ge w_i \quad (\text{能装下，在“上面的值”和“左上角+当前价值”中取最大})
\end{cases}
$$

**边界条件：**
$dp[0][j] = 0$ （没有物品时价值为0）
$dp[i][0] = 0$ （背包没容量时价值为0）

#### 2\. 求解过程（画表法）

我们构建一个表格，行表示物品 $i$（0\~4），列表示背包当前容量 $j$（0\~5）。

**填表步骤演示（以物品 2 为例）：**

  * 当计算 $dp[2][3]$ 时（物品2重3，容3）：
      * **不装：** 看正上方 $dp[1][3] = 3$。
      * **装入：** 看左上角（容量 $3-3=0$）$dp[1][0] + v_2 = 0 + 4 = 4$。
      * **决策：** $\max(3, 4) = 4$。

**完整 DP 表格：**

| 物品 $i$ \\ 容量 $j$ | 0 | 1 | 2 | 3 | 4 | 5 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **0 (初始)** | 0 | 0 | 0 | 0 | 0 | 0 |
| **1 ($w=2, v=3$)** | 0 | 0 | **3** | 3 | 3 | 3 |
| **2 ($w=3, v=4$)** | 0 | 0 | 3 | **4** | 4 | **7** |
| **3 ($w=4, v=5$)** | 0 | 0 | 3 | 4 | **5** | 7 |
| **4 ($w=1, v=2$)** | 0 | **2** | 3 | **5** | **6** | **7** |

**最终最大价值：** 表格右下角的值，即 **7**。

#### 3\. 结果回溯（确定装了谁）

从右下角 $dp[4][5]=7$ 开始倒推：

1.  **看物品 4 ($w=1, v=2$)：** $dp[4][5]=7$，上方 $dp[3][5]=7$。数值没变，说明**没装物品 4**。
2.  **看物品 3 ($w=4, v=5$)：** $dp[3][5]=7$，上方 $dp[2][5]=7$。数值没变，说明**没装物品 3**。
3.  **看物品 2 ($w=3, v=4$)：** $dp[2][5]=7$，上方 $dp[1][5]=3$。数值变了！说明**装了物品 2**。
      * 剩余容量：$5 - 3 = 2$。
4.  **看物品 1 ($w=2, v=3$)：** 当前在 $dp[1][2]=3$，上方 $dp[0][2]=0$。数值变了！说明**装了物品 1**。
      * 剩余容量：$2 - 2 = 0$。

**结论：** 选择装入 **物品 1** 和 **物品 2**。

#### 4\. 算法实现（伪代码）

老师如果要求写代码，写出这段核心逻辑即可：

```cpp
// 输入：容量 C，物品数量 N，重量数组 w，价值数组 v
// 输出：最大价值

int Knapsack(int C, int N, int w[], int v[]) {
    // 1. 初始化 dp 数组，全部填 0
    int dp[N+1][C+1]; 
    for(int j = 0; j <= C; j++) dp[0][j] = 0;

    // 2. 双重循环填表
    for (int i = 1; i <= N; i++) {           // 遍历每个物品
        for (int j = 1; j <= C; j++) {       // 遍历每个容量
            if (j < w[i]) {
                // 装不下，抄上面的
                dp[i][j] = dp[i-1][j];
            } else {
                // 能装下，比较“不装”和“装”
                // 这里的 dp[i-1][j-w[i]] 就是你说的“左上角”
                dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i]);
            }
        }
    }
    
    return dp[N][C]; // 返回表格右下角
}
```
