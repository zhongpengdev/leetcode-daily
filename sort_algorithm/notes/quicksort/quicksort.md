# 王道书QuickSort

核心模型：

1. 那个“拿饮料的人”想象一排座位，第一个人（基准 pivot）突然口渴，站起来去买水了。

+ 第一个坑：第一个座位现在是空的（这就是“坑”）。

+ 目标：买水的人回来时，要发现他左边全是矮子，右边全是高个子。

2. 三步走指令（以图 8.3.2 为例，Pivot=49）

+ 右边助教（j）先动：从最右边往左找，找一个比 49 小的人。

+ 找到了 27。填坑：把 27 踢到左边的空位（位置 $i$）坐下。

+ 新坑：现在 27 原本的位置（右边）变成了空坑。

+ 左边老师（i）再动：从左边往右找，找一个比 49 大的人。找到了 65。

+ 填坑：把 65 踢到刚才那个右边的空坑（位置 $j$）坐下。

+ 新坑：现在 65 原本的位置（左边）又变成了空坑。

3. 循环往复：$j$ 继续找小的填左坑，$i$ 继续找大的填右坑。

+ 相遇时刻：当 $i$ 和 $j$ 撞在一起时，空位只剩一个。

+ 归位：买水回来的 49 恰好坐进这个最后的坑位。

# 双基准快排 (Dual Pivot QuickSort)

## 给傻子讲

### 单基准回顾

普通快排：随机抓1个学生(pivot)，比他矮的站左边，比他高的站右边。然后左边右边各自再来一轮。

### 双基准：抓2个学生

随机抓2个学生 p1 和 p2，保证 p1 <= p2（矮的在左，高的在右）。这样全班被分成3堆：

```
[ 比p1矮的 ]  [ 比p1高但比p2矮的 ]  [ 比p2高的 ]
```

举例：p1=3, p2=7

```
数组：9 5 1 8 3 7 2 6 4
      ↓
比3矮：1 2
3到7之间：4 5 6
比7高：8 9
```

### 怎么分？用3根手指

```
lt (左边界)        i (扫描员)     gt (右边界)
 ↓                  ↓              ↓
[p1] [ ...待扫描... ] [p2]
```

规则：
- `a[i] < p1` → 丢到左边（和lt位置交换，lt右移，i右移）
- `a[i] > p2` → 丢到右边（和gt位置交换，gt左移，**i不动！**因为换过来的还没看）
- `a[i]` 在中间 → 不动，i继续往右走

扫完后，把p1放回lt-1的位置，p2放回gt+1的位置。

### 为什么比单基准快？

- 单基准：每次分2堆，比较 ~2n ln n 次
- 双基准：每次分3堆，比较 ~1.9n ln n 次（省了约5%）
- 而且双基准有更好的缓存局部性，实际跑起来更快
- Java 的 `Arrays.sort()` 对基本类型用的就是双基准快排（JDK 7起）

### 复杂度

| | 时间 | 空间 |
|---|---|---|
| 平均 | O(n log n)，常数更小 | O(log n) |
| 最坏 | O(n²) | O(n) |
