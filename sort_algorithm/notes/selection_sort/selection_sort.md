# 选择排序 (Selection Sort)

## 核心思想

每一轮从未排序的部分里选出**最小的那个**，放到已排序部分的末尾。

像打牌时从一堆牌里反复挑最小的放到手上。

## 图解过程

```
原始：[5, 3, 1, 4, 2]

第1轮：在 [5,3,1,4,2] 中找最小 → 1，和位置0交换
       [1, 3, 5, 4, 2]
        ^              (1已确定)

第2轮：在 [3,5,4,2] 中找最小 → 2，和位置1交换
       [1, 2, 5, 4, 3]
           ^           (2已确定)

第3轮：在 [5,4,3] 中找最小 → 3，和位置2交换
       [1, 2, 3, 4, 5]
              ^        (3已确定)

第4轮：在 [4,5] 中找最小 → 4，已经在位置3，不用换
       [1, 2, 3, 4, 5]
                 ^     (4已确定)

第5轮：只剩一个5，不用排了。
```

## 代码逻辑

```cpp
for i = 0 到 n-2:        // 每一轮
    minIdx = i            // 假设当前位置最小
    for j = i+1 到 n-1:  // 在未排序部分找真正最小的
        if a[j] < a[minIdx]:
            minIdx = j
    swap(a[i], a[minIdx]) // 把最小值放到位置 i
```

关键：**外层控制"放哪个位置"，内层控制"找最小值"。**

## 和冒泡排序的区别

| | 冒泡排序 | 选择排序 |
|---|---|---|
| 思路 | 相邻两两比较，大的冒到后面 | 每轮找最小的，放到前面 |
| 交换次数 | 多（每轮可能换好几次） | 少（每轮只换1次） |
| 最好情况 | O(n)（已有序，提前结束） | O(n²)（不管怎样都要扫） |

## 复杂度

| | 时间 | 空间 |
|---|---|---|
| 最好 | O(n²) | O(1) |
| 平均 | O(n²) | O(1) |
| 最坏 | O(n²) | O(1) |

**不管什么情况都是 O(n²)**，因为每轮都得把剩余元素扫一遍找最小值。

## 稳定性

**不稳定。**

反例：`[5, 5, 1]`

第1轮找到最小值 1，和位置0的 5 交换 → `[1, 5, 5]`

两个5的相对顺序变了（第一个5被换到了后面），所以不稳定。
