# 平衡二叉树 (AVL 树)

+ BST 的问题：**插入有序数据时会退化成链表，查找 O(n)**。
+ AVL 树通过**旋转**保持平衡，保证查找 O(log n)。

+ **平衡因子：** 任意节点的 `左子树高度 - 右子树高度` 必须是 -1、0、1。

    ```
    平衡:           不平衡:
        5               5
       / \             /
      3   7           3        高度差 = 2
     /               /
    1               1
    ```

+ **四种失衡情况及旋转：**

    **LL 型（右旋）：** 在左子树的左边插入导致失衡

    ```
    失衡:        右旋后:
        5           3
       /           / \
      3     →     1   5
     /
    1
    ```

    **RR 型（左旋）：** 在右子树的右边插入导致失衡

    ```
    失衡:        左旋后:
    1              3
     \            / \
      3    →     1   5
       \
        5
    ```

    **LR 型（先左旋后右旋）：** 在左子树的右边插入

    ```
    失衡:        先对3左旋:     再对5右旋:
        5             5              4
       /             /             / \
      3      →      4      →     3   5
       \           /
        4         3
    ```

    **RL 型（先右旋后左旋）：** 在右子树的左边插入

    ```
    失衡:        先对5右旋:     再对1左旋:
    1              1                4
     \              \              / \
      5      →       4     →    1   5
     /                \
    4                  5
    ```

+ **插入流程：** 按 BST 规则插入 → 从插入点往上检查平衡因子 → 失衡则旋转
