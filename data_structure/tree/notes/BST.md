# 二叉排序树 (Binary Search Tree, BST)

+ 中序遍历是有序递增的。

**定义：** 对于树中任意节点：
- 左子树上所有节点的值 **小于** 该节点的值
- 右子树上所有节点的值 **大于** 该节点的值
- 左右子树也分别是二叉排序树

**举例：** 依次插入 5, 3, 7, 1, 4, 6, 8

```
        5
       / \
      3   7
     / \ / \
    1  4 6  8
```

每个节点都满足：左 < 根 < 右。

**查找：** 和二分查找思想一样。从根开始，比当前节点小往左走，大往右走。

- 查找 4：5 → 3 → 4，3步
- 查找 6：5 → 7 → 6，3步
- 最坏情况：树退化成链表，O(n)；平衡时 O(log n)

**插入：** 和查找过程一样，找到空位就插入。
- 插入 2：5 → 3 → 1，2 > 1 往右，1没有右子节点，在1的右边插入2

```
        5
       / \
      3   7
     / \ / \
    1  4 6  8
     \
      2
```

**删除（最复杂）：** 分三种情况

+ **叶子节点：** 直接删除
+ **只有一个子节点：** 用子节点替代自己
+ **有两个子节点：** 找**中序遍历的后继节点**（右子树的最小值）来替代自己，然后删掉那个后继节点

例如删除 3（有两个子节点）：
- 3的右子树最小值是 4
- 用 4 替代 3
- 原来 4 的位置由它的右子树（空）填补

```
删除前:         删除后:
    5               5
   / \             / \
  3   7    →      4   7
 / \ / \         /   / \
1  4 6  8       1   6   8
```

**中序遍历 BST = 有序序列**，这是 BST 最重要的性质。
