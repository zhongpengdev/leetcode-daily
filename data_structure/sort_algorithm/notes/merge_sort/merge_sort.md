# 归并排序 (Merge Sort)

## 核心思想

**分而治之**：把数组不断拆成两半，直到每个子数组只剩一个元素，再两两合并。

```
          [5, 3, 1, 4, 2]
         /                \
     [5, 3, 1]          [4, 2]
     /       \          /     \
  [5, 3]    [1]      [4]     [2]
  /    \
[5]    [3]

拆到底了，开始合并 ↑

  [3, 5]    [1]      [2, 4]
     \       /          \    /
     [1, 3, 5]        [2, 4]
          \            /
        [1, 2, 3, 4, 5]
```

## 关键步骤：合并 (merge)

合并是唯一真正做事的步骤。把两个**已排序**的子数组合成一个有序数组：

```
左：[3, 5]    右：[1, 4]

比较：3 vs 1 → 取 1，结果：[1]
比较：3 vs 4 → 取 3，结果：[1, 3]
比较：5 vs 4 → 取 4，结果：[1, 3, 4]
右数组空了 → 把 5 放进去，结果：[1, 3, 4, 5]
```

用两个指针分别指向左右子数组的开头，谁小取谁。

## 伪代码

```
merge_sort(array, left, right):
    if left >= right: return          // 只剩一个元素，不用排

    mid = (left + right) / 2
    merge_sort(array, left, mid)      // 排左半
    merge_sort(array, mid+1, right)   // 排右半
    merge(array, left, mid, right)    // 合并左右
```

## 复杂度分析

| 属性 | 值 |
|------|------|
| 最好时间 | O(n log n) |
| 平均时间 | O(n log n) |
| 最坏时间 | O(n log n) |
| 空间复杂度 | O(n) — 需要临时数组做合并 |
| 稳定性 | **稳定** |

**时间为什么是 O(n log n)？**

```
一共 log(n) 层（每次对半切）
每层做 n 次比较（所有子数组加起来遍历一遍）
n × log(n) = O(n log n)
```

**为什么稳定？**

合并时如果左右元素相等，**优先取左边的**，相同元素的相对顺序不会变。

## 与快排、堆排对比

| | 快排 | 堆排序 | 归并排序 |
|---|---|---|---|
| 平均时间 | O(n log n) | O(n log n) | O(n log n) |
| 最坏时间 | O(n²) | O(n log n) | O(n log n) |
| 空间 | O(log n) | O(1) | O(n) |
| 稳定性 | 不稳定 | 不稳定 | **稳定** |

归并排序的代价是**额外空间 O(n)**，换来的是**最坏情况也是 O(n log n)** 和**稳定性**。
