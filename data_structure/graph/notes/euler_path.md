# 欧拉路径与欧拉回路

## 定义

- **欧拉路径（Euler Path）**：经过图中每条边恰好一次的路径。
- **欧拉回路（Euler Circuit）**：起点和终点相同的欧拉路径。

---

## 存在条件

| 类型 | 无向图 | 有向图 |
|------|--------|--------|
| **欧拉回路** | 所有顶点度数为偶数 | 所有顶点入度 = 出度 |
| **欧拉路径** | 恰好 2 个顶点度数为奇数 | 恰好 1 个顶点出度 = 入度+1，1 个入度 = 出度+1 |

---

## Hierholzer 算法

```
stack<int> circuit;
void euler(int u) {
    while (!adj[u].empty()) {
        int v = adj[u].back(); adj[u].pop_back();
        euler(v);
    }
    circuit.push(u);
}
```

**时间复杂度：** O(m)

---

## 注意

- 找到的回路是逆序存储在栈中，输出时需要反转。
- 如果图不连通且存在多条边，需要分别处理每个连通分量。
