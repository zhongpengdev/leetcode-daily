# 图的基本概念、分类与存储

## 基本概念

- **图** G = (V, E)：由顶点集合 V 和边集合 E 组成。
- **顶点（Vertex / Node）**：图中的基本元素。
- **边（Edge）**：顶点之间的连接关系。
- **度（Degree）**：与顶点相连的边的数量。
  - **入度（In-degree）**：指向该顶点的边数（有向图）。
  - **出度（Out-degree）**：从该顶点出发的边数（有向图）。
- **路径（Path）**：从一个顶点到另一个顶点经过的顶点序列。
- **环（Cycle）**：起点和终点相同的路径。
- **连通（Connected）**：任意两个顶点之间都存在路径。
- **权（Weight）**：边上的数值，表示代价、距离等。

---

## 图的分类

### 按边的方向

| 类型 | 特点 |
|------|------|
| **无向图（Undirected）** | 边没有方向，(u, v) 和 (v, u) 等价 |
| **有向图（Directed）** | 边有方向，<u, v> 和 <v, u> 不同 |

### 按边是否有权

| 类型 | 特点 |
|------|------|
| **无权图** | 边无权重，可视为所有边权为 1 |
| **有权图（Weighted）** | 边附带权重值 |

### 按连通性

| 类型 | 特点 |
|------|------|
| **连通图** | 无向图中任意两点可达 |
| **非连通图** | 存在不可达的顶点对，由多个**连通分量**组成 |
| **强连通图** | 有向图中任意两点互相可达 |
| **弱连通图** | 有向图忽略方向后是连通的 |

### 特殊图

- **完全图**：任意两个不同顶点之间都有边。无向完全图有 n(n-1)/2 条边，有向完全图有 n(n-1) 条。
- **稀疏图**：边数远小于 n² 的图（一般 |E| << n²）。
- **稠密图**：边数接近 n² 的图。
- **二分图（Bipartite）**：顶点可分为两个不相交集合，每条边连接两个集合中的顶点。
- **树**：无环连通无向图，n 个顶点恰好 n-1 条边。
- **DAG（有向无环图）**：无环的有向图，拓扑排序的基础。

## 图的存储方式

### 1. 邻接矩阵（Adjacency Matrix）

用二维数组 `G[n][n]` 存储，`G[i][j]` 表示顶点 i 到 j 的边（或权重）。

```
// 无权图：0/1 表示是否有边
// 有权图：存储权重值，无边用 INF 或 0 表示

int G[MAXN][MAXN];

// 添加边
G[u][v] = 1;       // 无向图
G[u][v] = 1;       // 有向图（只需单向）
G[u][v] = weight;  // 有权图
```

**特点：**
- 空间复杂度：O(n²)
- 查询边是否存在：O(1)
- 适合稠密图
- 浪费空间于稀疏图

### 2. 邻接表（Adjacency List）

用数组 + 链表（或 vector）存储每个顶点的邻居。

```
// C++ 实现
vector<pair<int, int>> adj[MAXN];  // adj[u] = {v, weight}

void addEdge(int u, int v, int w) {
    adj[u].push_back({v, w});
    adj[v].push_back({u, w});  // 无向图需加双向
}
```

**特点：**
- 空间复杂度：O(n + m)，m 为边数
- 遍历邻居：O(度数)
- 适合稀疏图
- 实际中使用最多

### 3. 边列表（Edge List）

将所有边存入列表，每条边记录 (u, v, weight)。

```
struct Edge {
    int u, v, w;
};
vector<Edge> edges;

// Kruskal 算法常用
```

**特点：**
- 空间：O(m)
- 适合按权排序（如 Kruskal）
- 查询某条边效率低

### 存储方式对比

| 操作 | 邻接矩阵 | 邻接表 | 边列表 |
|------|---------|--------|--------|
| 空间 | O(n²) | O(n+m) | O(m) |
| 判断边 u→v | O(1) | O(度(u)) | O(m) |
| 遍历 u 的邻居 | O(n) | O(度(u)) | O(m) |
| 添加边 | O(1) | O(1) | O(1) |
| 删除边 | O(1) | O(度(u)) | O(m) |
