# 切片 (Slice)

切片是 Go 最常用的数据结构，底层是对数组的引用。

## 创建

```go
// 字面量
s := []int{1, 2, 3}

// make(类型, 长度, 容量)
s := make([]int, 0, 10)  // 长度0，容量10

// 从数组创建
arr := [5]int{1, 2, 3, 4, 5}
s := arr[1:4]  // [2, 3, 4]

// 截取语法
s := arr[:2]   // 前2个
s := arr[2:]   // 从第2个到末尾
s := arr[:]    // 全部
```

## 三要素

切片内部是一个结构体，包含三个字段：

```
┌──────────┬────────┬────────┐
│  pointer │ length │  cap   │
│  (指向底层数组) │ (长度)  │ (容量)  │
└──────────┴────────┴────────┘
```

```go
s := make([]int, 3, 5)
len(s)  // 3，当前有几个元素
cap(s)  // 5，底层数组最多能装几个
```

## 增

### append

```go
s := []int{1, 2}
s = append(s, 3)          // [1, 2, 3]
s = append(s, 4, 5)       // [1, 2, 3, 4, 5]

// 拼接另一个 slice
s2 := []int{6, 7}
s = append(s, s2...)      // [1, 2, 3, 4, 5, 6, 7]
```

**注意**：append 可能返回新的底层数组，必须用返回值接收。

### append 扩容机制

当 `len == cap` 时，append 会分配更大的底层数组：
- 容量 < 1024：翻倍
- 容量 >= 1024：增长 25%

## 删

Go 没有内置删除操作，用切片拼接：

```go
s := []int{1, 2, 3, 4, 5}

// 删除下标 i 的元素
i := 2
s = append(s[:i], s[i+1:]...)  // [1, 2, 4, 5]

// 删除前 n 个
s = s[n:]

// 删除后 n 个
s = s[:len(s)-n]
```

## 改

直接下标赋值：

```go
s := []int{1, 2, 3}
s[1] = 20  // [1, 20, 3]
```

## 查

```go
s := []int{1, 2, 3, 4, 5}

// 下标访问
v := s[2]  // 3

// 遍历查找
for i, v := range s {
    if v == 3 {
        fmt.Println("找到，下标:", i)
    }
}
```

## copy（复制切片）

```go
src := []int{1, 2, 3}
dst := make([]int, len(src))
copy(dst, src)  // dst 是独立副本，改 dst 不影响 src
```

**和直接赋值的区别**：

```go
a := []int{1, 2, 3}
b := a          // b 和 a 共享底层数组！改 b 会影响 a
c := make([]int, len(a))
copy(c, a)      // c 是独立副本，改 c 不影响 a
```

## nil 和空切片

```go
var s1 []int       // nil 切片，len=0, cap=0, 没有底层数组
s2 := []int{}      // 空切片，len=0, cap=0, 有底层数组
s3 := make([]int, 0) // 同 s2

// 三者都可以安全地 len()、append()、for range
// 但 nil 切片 json 序列化是 null，空切片是 []
```

## 注意事项

1. **切片是引用类型**：多个切片可能共享底层数组，改一个可能影响另一个
2. **append 必须接收返回值**：`append(s, 1)` 不赋值给 s 是没用的
3. **大数组截取小切片会泄漏内存**：大数组不会被 GC 回收。用 `copy` 解决

```go
// 错误：a 的整个底层数组不会被回收
func getSmall() []int {
    a := make([]int, 1000000)
    return a[:3]  // 只要3个元素，但引用了100万个元素的数组
}

// 正确：复制出独立的小切片
func getSmall() []int {
    a := make([]int, 1000000)
    result := make([]int, 3)
    copy(result, a[:3])
    return result  // 底层数组只有3个元素，大的可以被回收
}
```
