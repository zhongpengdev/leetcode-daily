# 王道书QuickSort

核心模型：

1. 那个“拿饮料的人”想象一排座位，第一个人（基准 pivot）突然口渴，站起来去买水了。

+ 第一个坑：第一个座位现在是空的（这就是“坑”）。

+ 目标：买水的人回来时，要发现他左边全是矮子，右边全是高个子。

2. 三步走指令（以图 8.3.2 为例，Pivot=49）

+ 右边助教（j）先动：从最右边往左找，找一个比 49 小的人。

+ 找到了 27。填坑：把 27 踢到左边的空位（位置 $i$）坐下。

+ 新坑：现在 27 原本的位置（右边）变成了空坑。

+ 左边老师（i）再动：从左边往右找，找一个比 49 大的人。找到了 65。

+ 填坑：把 65 踢到刚才那个右边的空坑（位置 $j$）坐下。

+ 新坑：现在 65 原本的位置（左边）又变成了空坑。

3. 循环往复：$j$ 继续找小的填左坑，$i$ 继续找大的填右坑。

+ 相遇时刻：当 $i$ 和 $j$ 撞在一起时，空位只剩一个。

+ 归位：买水回来的 49 恰好坐进这个最后的坑位。
